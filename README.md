# soundwave-mac

Приложение в строке меню macOS для soundwave — подсветки стола в такт Apple Music.
Следит за тем, что играет в Music, берёт цвета обложки, слушает басы и шлёт всё это
на ESP32 (`soundwave-firmware`) по UDP.

## Запуск

```sh
make run        # собрать Soundwave.app, подписать и запустить
make install    # положить в /Applications
```

Иконка-волна появится в строке меню. В окне по клику:

- обложка, трек и палитра обложки (полоска: цвета слева направо, ширина — доля площади);
- **Подсветка** — вкл/выкл;
- **Один цвет / Сочетание** — режим (см. ниже);
- индикатор басов и **Чувствительность** к ударам;
- **IP платы** и статус связи.

При первом запуске macOS спросит три разрешения: управлять Music (трек и обложка),
записывать звук (только из Music, для ритма) и доступ к локальной сети (пакеты на плату).

## Режимы

- **Один цвет** — вся лента основным цветом обложки (самым большим по площади, но не чёрным).
  Пульс на ударах считает мак: шлёт готовый цвет 60 раз в секунду (`Fill`).
- **Сочетание** — цвета обложки на своих местах вдоль ленты; на ударах басов светлые цвета
  расширяются и ярчают. Мак шлёт палитру раз в секунду (`Palette`) и уровень басов 60 раз в секунду
  (`Level`), а рисует прошивка.

На паузе пакеты не шлются, и плата через 5 секунд сама уходит в радугу.

## Протокол

UDP, порт 4242. Шапка `'S' 0x01 <команда>`:

| Команда | Данные | Длина |
|---|---|---|
| `0x01` Fill | `R G B` | 6 |
| `0x02` Palette | `N`, затем N × `R G B W` (W — доля площади 0–255, цвета слева направо, N ≤ 5) | 4 + 4N |
| `0x03` Level | `L` — басы 0–255 | 4 |

Без платы пакеты удобно смотреть прямо на маке: IP `127.0.0.1` и

```sh
nc -ul 4242 | xxd
```

## Разработка

```sh
make            # список команд
make test       # тесты SoundwaveCore
make check      # всё, что гоняет CI: lint + test + app
make fmt        # отформатировать
```

Makefile собирает тулчейном Xcode (`DEVELOPER_DIR`), даже если `xcode-select` указывает на
Command Line Tools: у них бывает сломан плагин макросов Swift Testing.

| Где | Что |
|---|---|
| `Sources/SoundwaveCore/` | логика без системных API: протокол, палитра, анализ звука — всё под тестами |
| `Sources/Soundwave/` | приложение: Music, захват звука, отправка, меню |
| `Tests/SoundwaveCoreTests/` | тесты (Swift Testing) |
| `Resources/Info.plist` | описание `.app` и тексты запросов разрешений |
